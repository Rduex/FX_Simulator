## 三、五个模块各自干什么

### 1. Canvas 主题（`src/theme-canvas.js`，201 行）

**为什么需要**：K 线的涨跌颜色是写死在 `drawKline()` 里的十六进制值，改 CSS 管不到 canvas。

**做法**：在游戏执行前用 `Proxy` 包住 `canvas.getContext('2d')`，
把 `strokeStyle` / `fillStyle` 的赋值拦下来，按调色板映射。

| 关键词 | 说明 |
| --- | --- |
| `PALETTES.east` | 东亚习惯：**红涨绿跌**（默认） |
| `PALETTES.intl` | 国际习惯：绿涨红跌 |
| `setPalette()` | 运行时切换 |

**要改配色** → 改 `src/theme-canvas.js` 里的 `PALETTES`。

---

### 2. 主题样式（`src/theme-fx.css`，2867 行）

**作用**：整套深色交易终端风 UI，**全部是覆盖层**，不改游戏原始样式一个字节。

| 关键词 | 说明 |
| --- | --- |
| `:root` 设计令牌 | `--fx-bg` / `--fx-text` / `--fx-up` / `--fx-down` 等，改色改这里 |
| `--fx-up` | 涨色（默认 `#ef4444` 红） |
| `--fx-down` | 跌色（默认 `#22c55e` 绿） |
| `@media (max-width: 640px)` | 手机端布局 |
| `@media (min-width: 1180px)` | 桌面双栏（Multi-column 实现） |
| `.modal` / `.modal-panel` | 弹窗遮罩与面板几何 |

**要改整体配色** → 改 `:root` 里的令牌，不要在下面逐条改 `#xxxxxx`。

### 3. 游戏本体（`FX_game.html`，9149 行）

核心逻辑全在这里。**这一份是源码，不是产物**，改完要重新构建。

关键常量（行号对应 `FX_game.html`）：

| 常量 | 行 | 值 | 含义 |
| --- | --- | --- | --- |
| `START_EQUITY` | 4614 | `10000` | 开局资金 |
| `FEE_RATE` | 4615 | `0.00015` | 开仓手续费率（名义仓位 0.015%） |
| `MAINTENANCE` | 4616 | `0.8` | 强平线（亏到保证金的 80% 爆仓） |
| `CLOSE_LOCK_CANDLES` | 4626 | `1` | 开仓后最少持满几根 K 线才能手动平 |
| `LEV_MIN` / `LEV_MAX` | 4636–4637 | `1` / `888` | 杠杆范围 |
| `FREEDOM_GOAL` | 4699 | `20000000` | 通关目标（净资产 $2,000 万） |

**对外暴露的接口**：`window.FX`。本文件里另外四个模块全靠它工作。
常用字段：

```
FX.state              游戏状态（balance / positions / locked / paused / won / tickCount …）
FX.totalEquity()      账户总权益（= 现金 + 持仓 + 浮盈 + 家当 − 贷款）
FX.constants          START_EQUITY / FREEDOM_GOAL 等
FX.metaRef()          局外存档（家当、最佳成绩）
FX.renderAll()        手动重绘全部面板
FX.setPaused(bool)    暂停 / 恢复行情
FX.topUpPosition()    追保（账目由本体算）
FX.liqPriceOf()       强平价（统一口径）
```

> 💡 **改数值优先改常量，不要改散落各处的字面量**。比如想让通关更难，
> 改 `FREEDOM_GOAL` 一处即可，所有提示文案都引用它。

### 4. 追加保证金（`src/margin-ui.js`，666 行）

每张持仓卡下方常驻「＋ 追加保证金」，可自填金额并**实时预览**追加后的强平价与危险度。

**为什么不用自己算账**：预览数值是给本体函数传一个"保证金已加大"的浅拷贝算出来的 ——
本体改了强平口径，弹窗里的数字自动跟着变，不会漂移。

| 依赖的本体 API | 用途 |
| --- | --- |
| `FX.topUpPosition(id, amount)` | 真正改账（保证金 +x、占用 +x、余额不变） |
| `FX.liqPriceOf(p)` | 强平价 |
| `FX.dangerRatio(p)` | 危险度 |
| `FX.topUpNeed(p)` | 补到"安全区一半"需要多少钱 |

**注入方式**：`renderPositions()` 每次整体重建 `innerHTML`，会抹掉插入的节点，
所以用 `MutationObserver` 盯 `#positions`，重绘后幂等补回（已有就跳过）。

### 5. Toy 排行榜（`src/toy-rank.js`，813 行）

两个榜位 + 云存档。

| 常量 | 行 | 值 | 说明 |
| --- | --- | --- | --- |
| `BOARD_MONEY` | 46 | `1` | 榜位 1：资金榜 |
| `BOARD_SPEED` | 47 | `2` | 榜位 2：通关速度榜 |
| `SPEED_BASE` | 51 | `16777215` | 速度榜取反编码的基数 |
| `SUBMIT_COOLDOWN_MS` | 55 | `8000` | 同一榜位两次提交最小间隔 |
| `RANK_CACHE_MS` | 57 | `60000` | 榜单本地缓存时长 |
| `CLOUD_MAX_BYTES` | 520 | `1024` | 云存档 value 上限（SDK 硬限制） |
| `CLOUD_WRITE_INTERVAL_MS` | 523 | `120000` | 云存档最短写入间隔 |

#### 计分口径

| 榜位 | 比什么 | `score` 编码 |
| --- | --- | --- |
| 1 · 资金榜 | 净资产（`FX.totalEquity()`，与游戏内通关目标同一口径） | `floor(净资产)` |
| 2 · 速度榜 | 从 $10,000 做到 $2,000 万的用时 | `16777215 − 用时分钟数` |

> ⚠️ **速度榜为什么是"减"**：Toy 的 `submitScore` 只支持"分数越高排名越高"，
> 而"越快越好"是相反的。取反后，用时越短分数越大，排序才正确。
> 页面展示时会反解回分钟数，玩家看到的是「12.0 分钟」而不是分数。

#### 云存档

| 项目 | 值 |
| --- | --- |
| key | `fx_save_v1`（**只用一个 key**，SDK 限制单 Toy 最多 128 个） |
| 存什么 | 现金、家当、最佳成绩（体积压到 1024 字节内，超了先丢家当再丢最佳成绩） |
| 覆盖策略 | **只有云端比本地更好时才覆盖** —— 否则旧云档会盖掉玩家刚玩的进度 |
| 写入时机 | 通关 / 页面隐藏 / 每 2 分钟（有闸门） |

#### 限流保护

Toy 的云存储与排行榜**按 Toy 共享额度**，玩家越多越容易触发 `307044`：

| 接口 | 策略 |
| --- | --- |
| `submitScore` | 只在破纪录时提交（8 秒冷却 + 必须更高） |
| `getRankList` | 只在玩家打开排行榜时拉，缓存 60 秒 |
| `setCloudStorage` | 通关 / 隐藏 / 2 分钟一次 |
| 失败 | 退避 1 次（1 秒 → 2 秒），**绝不立即重试** |

## 六、构建产物的额外说明

`build-toy.js` 做的不只是拼接，它还：

1. **幂等剥离**：如果输入的 `FX_game.html` 本身已经含注入块（比如它曾是个产物），
   先按**导出签名**剥掉旧的再注入，避免出现两份模块（两份 `GhostUI` 会让界面挂两套）。
2. **强制校验**：产物缺任何一项能力、含幽灵模块、含自建 `/api/*` 调用 → **构建直接失败**。
3. **换行符统一**：注入内容统一成 LF，避免"重新构建一次就差几千行"（实际内容没变）。

产物目录 `dist-toy/` 里还有 `_headers` / `_redirects`（给 Cloudflare Pages / Netlify 用），
上传 Toy 时用不到，可以忽略。

## 七、上传 B站 Toy

1. 打开 B站 Toy 创作中心
2. 上传 `dist-toy/fx-simulater.html`（**只需要这一个文件**）
3. 榜位说明填：榜位 1 = 资金榜（净资产），榜位 2 = 通关速度榜

上传后建议先在 App 内实测三件事：
- 首次进入是否弹出教程
- 打完一局后榜上是否有自己
- 退出再进，进度是否还在（云存档）
